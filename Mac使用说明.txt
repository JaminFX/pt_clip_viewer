PT Clip Viewer — Mac 安装与日常使用
=================================

一、先安装到“应用程序”
1. 打开 PT_Clip_Viewer_3.9.10_macOS_Universal2.dmg。
2. 将 PT Clip Viewer.app 拖到 Applications（应用程序）文件夹。
3. 更新旧版时，先退出正在运行的 PT Clip Viewer，再选择替换。
4. 在访达左侧打开“应用程序”，从这里打开 PT Clip Viewer。
   请勿长期直接运行 DMG 中的 App，否则弹出磁盘镜像后快捷方式可能失效。

二、首次提示 Apple 无法验证时，在设置中允许打开
本软件目前没有 Apple Developer ID 签名和公证。仅在确认文件来自你信任的
发布来源时，才为这个 App 单独允许打开。

1. 先从“应用程序”双击打开一次，让系统显示拦截提示。
2. 关闭提示框，点屏幕左上角苹果菜单 >“系统设置”。
3. 进入“隐私与安全性”，向下滚动到“安全性”区域。
4. 找到有关 PT Clip Viewer 被阻止打开的提示，点“仍要打开 / Open Anyway”。
5. 如有要求，使用管理员密码或 Touch ID 授权。
6. 在再次弹出的确认框中点“打开”。以后通常可以直接启动。

如果看不到“仍要打开”：重新尝试启动一次，再回到“隐私与安全性”。
该按钮通常在尝试打开后约一小时内显示。旧版 macOS 的入口可能叫
“系统偏好设置 > 安全性与隐私 > 通用”。公司管理的 Mac 可能受管理员策略限制。
若提示“会损坏电脑”、被认定为恶意软件或文件确已损坏，请停止打开并核对来源；
此处的允许操作针对“未验证开发者 / 尚未公证”提示。

三、固定到底部程序坞（Dock）——最方便的启动方式
1. 成功打开已安装到“应用程序”的 PT Clip Viewer。
2. 在底部 Dock 中右键图标；触控板可双指点按，也可按住 Control 点按。
3. 选择“选项 > 在程序坞中保留 / Keep in Dock”。
4. 以后即使退出软件，图标也会保留，单击即可打开。
也可以直接把访达“应用程序”中的 App 图标拖到 Dock 的应用区域。

四、放到“启动台”或新版系统的“App”列表
Mac 没有 Windows 的“开始菜单”。旧版系统可打开“启动台（Launchpad）”
并搜索 PT Clip Viewer；把 App 安装到“应用程序”后，系统会将其纳入应用列表。
较新 macOS 可能显示“App”列表，或通过“聚焦”查看应用。
通用快捷方式：按 Command + 空格，输入 PT Clip Viewer，再按 Return。
如果刚安装后还搜不到，先从访达“应用程序”打开一次，再稍候重试。

五、基本使用
- 打开或拖入 Pro Tools 导出的 .txt 文本。
- 左侧选择轨道，中间查看片段时间码。
- 复制当前轨道，或把轨道添加到右侧分组，再复制勾选分组。
- Command+O：打开文件；Command+Z：撤销；Command+Shift+Z：回撤。
- Command+Q：退出；Command+W：关闭窗口。
- 用户设置保存在 ~/Library/Application Support/PT Clip Viewer/，更新安装不会主动删除。

PT Clip Viewer 安全审核报告

2026-11-09 · 3.9.9 → 3.9.10 · 已修复项、验证证据与剩余风险

一、项目概况与结论

审核日期：2026-11-09（Australia/Sydney）。项目：PT Clip Viewer，审核基线 3.9.9，修复后交付 3.9.10。

项目为离线桌面应用：Python + Tkinter/ttk + tkinterdnd2；使用 PyInstaller onedir 打包，Windows 使用 Inno Setup，Mac 使用 Universal 2 DMG。无 Web 服务、数据库、浏览器扩展或用户登录系统。

直接 Python 依赖 3 个；跨平台锁文件固定 10 个不同包（Windows 实际 9 个，Mac 实际 8 个）。Python、Tcl/Tk、TkDnD 和系统构建工具单列核对。临时图标制作 Node 工具不属于产品依赖，已单独 npm audit 并随临时文件清理。

确认并修复了可重现的文本解析拒绝服务问题、读取边界和发布供应链配置问题。未发现已证实的应用命令执行、注入、越权或真实凭据泄露。更新后 pip-audit 未报告已知依赖漏洞；这不等于永远没有漏洞，也不替代运行路径分析。

严重性列采用上游公告的 Critical/High 标记时，说明列同时注明本项目是否能触发。尤其不能把 Pillow 的上游 Critical 直接解释成这个时间码工具存在可利用的远程代码执行。

五、逐文件代码审查与已修复改动

pt_clip_viewer.py / edl_parser.py：导出文本只作为数据处理，不执行内容。原正则存在可重现回溯放大；已用逐行扫描和固定时间字段查找替代。限制在读取函数内部实施，验证已打开描述符、拒绝非普通文件，最多读取 20 MB+1；UI 捕获 OSError/ValueError。UTF-16 仅在有 BOM 时尝试，避免偶数字节 GBK 被错误解码。

pt_platform.py：设置保存在用户目录，无密码或凭据；允许用户选择本地/网络文件属于功能授权，不应误报为路径穿越。配置保存仅为两个布尔偏好。未发现跨用户读写或权限提升。

ui_widgets.py / aa_graphics.py：只使用固定颜色、随包图标数据和控件尺寸；没有 eval、动态远程脚本或系统命令。抗锯齿图像采用 PNG 数据及标准库 zlib 生成，保留原版 LOGO。没有把导出片段名称当作 Tcl 脚本执行。

ui_validation.py / 应用 smoke 分支：移除可被 -O 优化掉的 assert，改为显式异常；截图调用限定为 Mac 系统绝对路径。发布标记在运行前清除，避免旧结果掩盖新失败。

build_app.py / macos_universal.py / verify_macos_dmg.py：所有子进程参数为数组，无 shell=True；文件内容不拼接到 shell。Mac 系统命令采用绝对路径，所有核心 Mach-O 要求包含两个架构；TkDnD 只对明确的架构目录做例外并检查匹配架构。vendor 库先核对哈希，再复制与签名。

build_windows.ps1 / build_macos.command / run_macos.command / requirements*.lock：固定直接及间接依赖、发行文件哈希，只接受二进制轮子。Windows 安装保持 PrivilegesRequired=lowest，不要求管理员权限、不启用应用提权。

.github/workflows/macos-universal.yml：只有手动 workflow_dispatch，没有 pull_request_target；Action 固定提交、token 只读，构建 checkout 不保留凭据。Python 安装包固定版本与哈希；源码目录由固定条件赋值，没有把 PR 标题、分支文字等不可信上下文直接插入脚本。下载制品检查摘要与路径归属后解压。

tools/audit_secrets.py / tools/runtime_inventory.py：只用于本地审计与版本记录；秘密匹配只输出规则、位置和指纹，不输出值。GitHub 下载辅助脚本仅在内存读取系统 Git Credential Manager，跨域重定向会移除 Authorization，随临时构建目录删除，不进入交付 App。

verify_release.py / verify_security.py / verify_universal.py / hooks-macos：测试覆盖编码、迁移、滚轮、恶意长空白行、字节上限、非普通文件、哈希、优化模式验证门和架构选择。包钩子只调整已固定依赖的打包路径。

不适用项：无 SQL/NoSQL、HTTP 服务、HTML 用户内容渲染、鉴权接口、CORS、浏览器扩展、WebView、IPC RPC、反序列化用户 pickle/yaml、用户压缩包上传或动态远程代码加载。因此没有把这些不存在的接口虚构成发现。

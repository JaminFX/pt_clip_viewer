PT Clip Viewer 3.9.7
====================

交付内容
1. release/PT_Clip_Viewer_Setup_3.9.7_Windows_x64.exe：Windows 安装程序。
   双击安装，无需安装 Python；支持开始菜单、可选桌面快捷方式及卸载。
2. release/PT_Clip_Viewer_3.9.7_macOS_Source.zip：Mac 源码与一键构建工具。
   这是源码包，不是已构建好的 .app 或 .dmg。
   Universal 2 更新包为 release/PT_Clip_Viewer_3.9.7_macOS_Universal2_BuildKit.zip。
   无 Mac 的用户可参照“Mac通用版云端打包说明.txt”，使用附带的 GitHub Actions。
3. 原来的 pt_clip_viewer.exe、_internal 和 v3_9_6.py 原样保留。

Mac 使用与构建
---------------
本次开发环境是 Windows，没有在真实 macOS 上运行验证。
PyInstaller 需要在对应系统上构建，最终 Mac 应用必须在 Mac 上生成。

1. 从 https://www.python.org/downloads/macos/ 安装带有 Tk 的 Python 3.12 universal2。
   不建议直接使用系统自带 Python；构建脚本会检查是否使用原生 Aqua Tk。
2. 解压 Mac 源码包。
3. 在“终端”输入 bash 和空格，将 build_macos.command 拖入终端，再按回车。
   第一次构建需要联网安装依赖。
   如果已赋予执行权限，也可双击 build_macos.command。
4. 成功后 release 目录生成 PT_Clip_Viewer_3.9.7_macOS_Universal2.dmg。
   主程序、Python、Tk 同时包含 Intel x86_64 与 Apple Silicon arm64；
   拖拽库包含分别供两种架构加载的组件。构建会检查每一项，缺失时停止。
   本机构建仅执行当前架构的启动检查；云端工作流对同一 DMG 执行双架构检查。
5. 打开 DMG，把 PT Clip Viewer.app 拖入 Applications 即可安装。

如果只想在 Mac 上先运行源码，按上述终端方法运行 run_macos.command。
也可以设置 PT_PYTHON 为指定 Python 路径后运行脚本。
构建会对打包后的界面、TkDnD、中文导入和剪贴板执行自检。
Mac 包只做本地 ad-hoc 签名，没有 Apple Developer ID 签名和公证；
向其他人分发前，需要在 Mac 上完成签名、公证和实际操作验收。

本次适配
--------
Mac 使用 PingFang SC / Menlo 字体，不再运行 Windows 字体拦截。
修复 Mac 触控板小幅滚动没有响应的问题。
Mac 撤销为 Command+Z，重做为 Command+Shift+Z；打开为 Command+O。
增加 Mac 文件菜单和 Command+W 关闭窗口。
UTF-8 导出文件优先按 UTF-8 解析，避免中文被当成 GBK。
设置保存在用户可写目录：
  Mac：~/Library/Application Support/PT Clip Viewer/pt_clip_viewer.ini
  Windows：%LOCALAPPDATA%/PT Clip Viewer/pt_clip_viewer.ini
首次会读取旧程序旁的 ini；保存时迁移到新目录。卸载保留用户设置。

重新构建 Windows
----------------
安装 Python 3.12 和 Inno Setup 6，在 PowerShell 运行：
  powershell -ExecutionPolicy Bypass -File .\build_windows.ps1
此脚本先创建独立 Python 环境，再生成应用和安装包。

验证
----
  python verify_release.py
  python pt_clip_viewer.py --smoke-test smoke.txt
实际 Mac 的拖拽、字体排版、快捷键和跨应用粘贴仍需在 Mac 上验收。
